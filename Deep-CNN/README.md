#Comparative Study of Deep Convolutional Neural Network Architectures Using Transfer Learning

Overview

This project presents a comparative study of deep Convolutional Neural Network (CNN) architectures and demonstrates transfer learning using a pretrained CNN model.

The experiment studies the evolution of CNN architectures including LeNet-5, AlexNet, VGG16, GoogleNet and ResNet, followed by implementation of transfer learning using MobileNetV2 on the CIFAR-10 dataset.

The experiment also covers fine-tuning, dilated convolution, transpose convolution, model evaluation and hyperparameter studies.

---

Objectives

- Study the evolution of deep CNN architectures.
- Compare LeNet-5, AlexNet, VGG16, GoogleNet and ResNet.
- Understand transfer learning.
- Fine-tune pretrained CNN models.
- Compare classification performance of different architectures.
