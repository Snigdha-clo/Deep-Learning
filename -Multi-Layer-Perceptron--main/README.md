# -Multi-Layer-Perceptron-
 Multi-Layer Perceptron (MLP) for Multi-Class Image Classification.
This project uses a Multi-Layer Perceptron (MLP) with TensorFlow/Keras to classify images from the Fashion-MNIST dataset into 10 clothing categories. It includes the complete pipeline: data exploration, preprocessing, model construction, training, evaluation, and automatic hyperparameter optimization with RandomizedSearchCV using the SciKeras wrapper.
